# GAWEDEUI — Neo-brutalist edition

GAWEDEUI task management interface in a warm, colorful Neo-brutalist style, adapted from the visual principles of the references provided by the user. Existing navigation and application pages are retained, with responsive layouts for mobile.

## Files

- `index.html` — application markup and page structure
- `styles.css` — application styles and responsive Neo-brutalist theme
- `app.js` — application interactions and realtime clock
- `tailwind.config.js` — Tailwind theme configuration

## Run

Open `index.html` in a modern browser. The project keeps the existing CDN-based setup; internet access may be needed for its external libraries and fonts.
